# 分级代理商仓库系统 · MVP 阶段功能清单（共46项）


## 商品管理中心

### 商品录入
- 单表单录入平铺字段商品（名称/规格/型号/品牌/单位/价格/库存，保存即上架可售） [租户端] (服务端16h / 移动端24h)
- MVP 英文界面（界面文案英文，不做多语言切换） (服务端2h / 移动端22h)

### 商品批量导入
- 下载 Excel 商品导入模板 (服务端3h / 移动端3h)
- 批量导入商品（逐行校验必填/格式/重复） (服务端16h / 移动端6h)
- 校验失败行导出回执修正后重导 (服务端8h / 移动端4h)

### 商品分类管理
- 平台统一平级分类归属（一商品可属多分类） (服务端8h / 移动端8h)

## 采购与交易

### WhatsApp 集成与 AI 助手
- 单据变更触发推送 WhatsApp 链接 (服务端26h / 移动端6h)
- 点击链接跳转 H5 对应单据详情 (服务端10h / 移动端22h)
- AI 基于询价明细生成报价草稿 (服务端30h / 移动端2h)
- AI 生成订单摘要供确认 (服务端24h / 移动端8h)

### 询价管理
- 提交询价单 (服务端6h / 移动端4h)
- 接收报价后生成采购订单 (服务端12h / 移动端4h)
- 跟踪订单状态 (服务端6h / 移动端8h)
- 填写商品明细/收货仓/交货日期生成询价单 (服务端4h / 移动端6h)
- 跟踪询价状态 (服务端2h / 移动端2h)

### 报价管理
- 查看询价单 (服务端6h / 移动端6h)
- 提交报价单 (服务端10h / 移动端10h)
- 报价自动通知采购方 (服务端6h / 移动端2h)

### 采购订单管理
- 在线创建采购订单（校验可用库存与价格合规、记录代理链路） (服务端22h / 移动端12h)

## 仓库管理

### 默认仓库与库存台账
- 查看库存列表 (服务端6h / 移动端10h)
- 调整库存数量 (服务端8h / 移动端8h)
- 每次变更生成库存流水记录 (服务端8h / 移动端0h)

### 订单出库
- 审核订单 (服务端10h / 移动端6h)
- 办理出库（出库后自动减少库存） (服务端32h / 移动端12h)
- 生成出库单/发货单 (服务端8h / 移动端8h)
- 出库确认后自动生成路单（含商品明细与物流信息） (服务端10h / 移动端2h)
- 推送采购方确认路单链接 (服务端6h / 移动端6h)

### 收货验收
- 根据发货单验收 (服务端4h / 移动端6h)
- 确认后自动增加库存并生成入库单 (服务端16h / 移动端4h)
- 验收上游发货单（通过/部分差异/拒收） (服务端8h / 移动端8h)
- 自动生成入库单并增加库存 (服务端24h / 移动端8h)

### 库存流水查看
- 查询库存流水（变动类型/前后库存/关联单号/操作人，按 SKU/仓库/时间筛选） (服务端14h / 移动端10h)

## 单据管理

### 单据总览与统一编号
- 六类单据统一自动编号（前缀-日期-序列，并发唯一） [平台端、租户端] (服务端20h / 移动端4h)

### 单据列表与查询
- 统一单据列表多维筛选（单据号/类型/状态/日期/往来方/SKU，分页排序与自定义列） (服务端20h / 移动端30h)

### 单据详情查看
- 单据详情三段式展示（单据头+明细+流转时间线） (服务端14h / 移动端26h)

### 批量操作、打印与导出
- 按模板打印单据（防伪水印/条码） (服务端14h / 移动端8h)
- 导出 PDF/Excel（记数据外发事件） (服务端14h / 移动端4h)

## 财务中心

### 发票管理
- 订单履约后自动开具销售发票（FP-） [租户端] (服务端36h / 移动端6h)
- 下载销售发票 (服务端14h / 移动端10h)

## 国际化配置

### 货币代码
- 价格字段旁带货币代码（CNY/USD/NGN），单据金额按货币代码呈现 [平台端、租户端] (服务端14h / 移动端10h)

## 账号权限管理

### 租户管理
- 创建租户（类型/国家/最大代理层级） (服务端14h / 移动端10h)
- 通过 TenantRelation 建立供货关系（同类型关系唯一） (服务端10h / 移动端6h)
- 停用违规租户（二次确认、停用后禁登、数据保留） (服务端10h / 移动端6h)

### 账号管理
- 仅创建账号（姓名/手机号/密码）开通访问，权限拉平 (服务端8h / 移动端8h)
- 创建下级代理商主账号 [租户端] (服务端8h / 移动端8h)
- 录入并绑定其 WhatsApp 账号 (服务端10h / 移动端14h)
